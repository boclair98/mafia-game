# 검은 자정 개인정보 처리방침

시행일: 2026-08-12 · 경기 복구 저장 관련 갱신: 2026-11-22

검은 자정은 게임 제공에 필요한 최소한의 데이터만 처리합니다.

## 처리하는 정보

- 플레이어가 정한 닉네임과 익명 재접속 식별키
- 로그인 사용자의 플랫폼 식별자와 최고 점수
- 게임 방 상태, 텍스트 채팅, 신고 대상과 신고 사유
- 사용자가 기기에 저장한 음향 설정과 차단 목록

음성 채팅은 WebRTC를 통해 참가자 사이에 실시간 전송되며 서버에서 녹음하거나 저장하지 않습니다. 마이크 권한은 음성 채팅 참여 시에만 요청하고, 거부해도 텍스트 게임을 이용할 수 있습니다.

## 이용 목적과 보관

정보는 실시간 매치 운영, 재접속, 랭킹, 악용 방지와 신고 검토에 사용됩니다. 운영에서는 서버 장애 후 복구를 위해 닉네임·좌석 식별키·비공개 역할·텍스트 대화·게임 기록이 비공개 PostgreSQL 체크포인트에도 저장됩니다. 기본 마지막 활동 후24시간이 지나면 복구 대상에서 제외하고 다음 서버 정리 시 삭제합니다. 서버가 정지/zero-scale 상태면 실제 삭제 시점은 늦어질 수 있습니다. 복구 저장을 끈 로컬 모드는 메모리만 사용합니다.

로그인한 사용자의 최고 점수·XP·사건 결과 요약은 별도의 기록으로 보관됩니다. 기기 설정과 차단 목록은 브라우저 또는 앱 로컬 저장소에서 사용자가 앱 데이터를 삭제할 때까지 보관됩니다. 체크포인트는 다른 플레이어에게 전체 공개하는 리플레이나 음성 녹음이 아닙니다. 선택적 TURN 연결 시 단기 인증 식별자를 중계 서버와 교환하지만 공유 인증 비밀을 브라우저에 제공하지 않습니다.
