# 검은 자정 개인정보 처리방침

시행일: 2026-08-12

검은 자정은 게임 제공에 필요한 최소한의 데이터만 처리합니다.

## 처리하는 정보

- 플레이어가 정한 닉네임과 익명 재접속 식별키
- 로그인 사용자의 플랫폼 식별자와 최고 점수
- 게임 방 상태, 텍스트 채팅, 신고 대상과 신고 사유
- 사용자가 기기에 저장한 음향 설정과 차단 목록

음성 채팅은 WebRTC를 통해 참가자 사이에 실시간 전송되며 서버에서 녹음하거나 저장하지 않습니다. 마이크 권한은 음성 채팅 참여 시에만 요청하고, 거부해도 텍스트 게임을 이용할 수 있습니다.

## 이용 목적과 보관

정보는 실시간 매치 운영, 재접속, 랭킹, 악용 방지와 신고 검토에 사용됩니다. 익명 방 상태와 채팅은 서버 메모리에 일시적으로 존재하며 방이 만료되면 삭제됩니다. 기기 설정과 차단 목록은 브라우저 또는 앱 로컬 저장소에서 사용자가 앱 데이터를 삭제할 때까지 보관됩니다.

## 문의와 삭제 요청

저장소 Issues 또는 배포 서비스의 운영 연락처를 통해 열람·정정·삭제를 요청할 수 있습니다. 정식 출시 전 스토어에 표시할 운영자 이메일과 사업자 정보를 이 문서에 추가해야 합니다.
