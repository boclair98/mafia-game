# 검은 자정 커뮤니티 가이드라인

검은 자정에서 속임수는 역할극 안에서만 허용됩니다. 플레이어에 대한 존중은 항상 지켜야 합니다.

다음 행위는 금지됩니다.

- 혐오, 차별, 성적 괴롭힘, 현실의 위협
- 개인정보 공개 또는 개인정보를 요구하는 행위
- 반복적인 욕설, 스팸, 음성 소음, 고의적인 게임 방해
- 불법 콘텐츠, 자해 조장, 미성년자에게 부적절한 콘텐츠
- 버그 악용, 계정 사칭, 신고 기능 악용

채팅 작성자 옆 `신고`를 누르면 운영 검토 대상으로 접수되며, `차단`을 누르면 해당 플레이어의 텍스트와 음성이 즉시 숨겨집니다. 긴급한 현실의 위험은 게임 신고만으로 해결하지 말고 지역 응급기관이나 경찰에 연락하세요.
