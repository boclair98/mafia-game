# Black Midnight — 검은 자정

[![Production checks](https://github.com/boclair98/mafia-game/actions/workflows/ci.yml/badge.svg)](https://github.com/boclair98/mafia-game/actions/workflows/ci.yml)
[![Play now](https://img.shields.io/badge/PLAY-black--midnight.coders.kr-bb263b)](https://black-midnight.coders.kr)

> 한 명이 죽었다. 범인은 아직 이 방 안에 있다.

Web, Android, iOS에서 같은 실시간 사건을 공유하는 모바일 우선 소셜 추리 게임입니다. `frontend/android`와 `frontend/ios`에는 Capacitor 네이티브 프로젝트가 포함되어 있으며, 웹 빌드 후 `pnpm native:sync`로 앱 셸을 갱신할 수 있습니다.

검은 자정은 4~12명이 모바일 또는 PC 브라우저에서 플레이하는 실시간 살인사건 추리 마피아 게임입니다. 밤마다 범인이 움직이고, 새벽에는 현장 감식 단서가 도착합니다. 플레이어는 음성 토론과 알리바이, 공개 투표 기록을 대조해 범인을 찾아야 합니다.

별도 설치나 회원가입 없이 바로 시작할 수 있습니다.

스토어 심사와 운영 준비 자료는 [출시 체크리스트](docs/STORE_RELEASE_CHECKLIST.md), [개인정보 처리방침](docs/PRIVACY.md), [커뮤니티 가이드라인](docs/COMMUNITY_GUIDELINES.md)에 정리되어 있습니다.

**운영 서비스:** [https://black-midnight.coders.kr](https://black-midnight.coders.kr)

## 30초 만에 시작하기

1. 운영 서비스에 접속합니다.
2. 게임에서 사용할 이름을 입력합니다.
3. 생성된 방에 입장한 뒤 `친구 초대` 링크를 공유합니다.
4. 사람이 부족하면 방장이 AI 좌석을 4명, 6명 또는 8명까지 채웁니다.
5. 실제 참가자는 `준비하기`를 누르고 방장이 게임을 시작합니다.

권장 인원은 6~8명입니다. 최소 4명부터 시작할 수 있고 최대 12명까지 참가할 수 있습니다.

## 평범한 마피아 게임과 무엇이 다른가

검은 자정은 단순히 밤에 한 명을 죽이고 낮에 투표하는 게임이 아닙니다. 한 판 전체가 하나의 사건 파일로 남습니다.

- 매일 새벽 진짜 범인을 포함하는 `현장 감식 단서`가 공개됩니다.
- 단서는 2~3명의 후보만 좁혀 주며 정답을 직접 알려주지 않습니다.
- 참가자는 판 시작 때 자신만 볼 수 있는 `봉인 증거` 한 장을 받고, 낮에 공개할지 숨길지 선택합니다.
- 마피아의 위조 증거도 같은 인장을 사용하므로 공개된 증거 자체가 정답을 보증하지 않습니다.
- 모든 생존자는 낮에 음성·채팅으로 자유롭게 토론합니다.
- 화면은 한 명씩 집중 발언자로 비춰 핵심 주장을 놓치지 않게 합니다.
- 질문, 공식 진술, 개인 판단, 투표, 최후 변론이 사건 기록에 연결됩니다.
- 투표가 끝나면 봉인된 표를 한 장씩 호명해 결과가 갑자기 지나가지 않게 합니다.
- 사망자는 생존자의 대화에 개입하지 않고 사건 기록을 토대로 최종 범인을 예측할 수 있습니다.
- 처형된 사람의 역할은 게임이 끝날 때까지 공개되지 않습니다.
- 종료 후 전체 배역과 결정적 거짓말을 시간순으로 복기할 수 있습니다.

핵심 추리 구조는 다음과 같습니다.

```text
현장 단서 확보
      ↓
개인 봉인 증거 공개 여부 결정
      ↓
용의자 후보 좁히기 · 알리바이 질문과 자유 토론
      ↓
진술·밤 행동·투표 기록 대조
      ↓
봉인 투표 순차 공개 · 최후 변론과 처형 판결
      ↓
사건 종료 후 전체 진실 복기
```

## 한 라운드의 진행

### 1. 비밀 역할과 봉인 증거 확인

서버가 역할을 무작위로 배정합니다. 자신의 역할과 같은 팀 정보만 확인할 수 있으며 다른 사람의 역할은 게임 종료 전까지 브라우저에 전송되지 않습니다.

각 참가자는 자신만 볼 수 있는 봉인 증거 한 장도 받습니다. 이 증거는 특정 생존자를 지목하는 대화의 출발점일 뿐 역할을 확정하는 판정이 아닙니다. 낮 토론 중 한 번 공개할 수 있고, 공개된 증거는 사건 기록에 남습니다. 공개 화면은 진짜 단서와 마피아가 받은 위조 단서를 구분하지 않습니다.

### 2. 밤의 행동

마피아는 습격할 사람을 고릅니다. 의사, 탐정, 경호원도 각자의 대상을 선택합니다. 마피아끼리는 밤에 비밀 채팅을 사용할 수 있습니다.

### 3. 새벽 사건 보고

사망, 치료 또는 경호 결과가 설정한 닉네임으로 발표됩니다. 예를 들어 플레이어 이름이 `이희승3`이면 `이희승3님이 죽었습니다.`라고 표시하고 진행 음성이 읽습니다.

그날 밤 사망한 플레이어는 단 한 번 유언을 남길 수 있습니다.

### 4. 현장 감식 단서

습격이 발생하면 감식반이 CCTV 음영 구역, 불완전한 지문, 섬유 조각, 키카드 기록 같은 단서를 공개합니다.

각 단서는 다음 원칙을 지킵니다.

- 후보 목록에는 실제 습격자가 반드시 포함됩니다.
- 무고한 용의자도 함께 포함돼 단서 하나만으로는 결론을 낼 수 없습니다.
- 단서 후보와 각 플레이어의 알리바이를 대조해야 합니다.
- 모든 단서는 사건 파일에 누적됩니다.

### 5. 봉인 증거 공개, 자유 토론과 집중 발언

낮에는 모든 생존자의 음성과 공개 채팅이 열립니다. 동시에 집중 발언자가 순서대로 바뀝니다.

집중 발언자는 이번 라운드의 핵심 주장을 한 번 봉인할 수 있습니다. 다른 참가자는 질문을 보내고 해당 발언자를 `신뢰`, `보류`, `의심`으로 비공개 평가할 수 있습니다.

공개된 현장 단서, 플레이어 증거, 단계에 따라 공개되는 평가 집계와 투표 수는 용의자 카드의 `공개 의심도`에 합산됩니다. 이 수치는 공개 정보 탐색을 돕는 UI 참고값이며 서버가 계산한 역할 확률이나 정답 판정이 아닙니다.

### 6. 공개 투표 호명

생존자는 자신을 제외한 한 명을 지목합니다. 투표가 끝난 뒤 전체 화면 연출에서 봉인된 표가 한 장씩 열리고, 누가 누구에게 투표했는지 순서대로 공개됩니다. 단독 최다 득표자가 없으면 피고 없이 밤으로 넘어갑니다.

### 7. 최후 변론과 최종 판결

최다 득표자는 바로 처형되지 않습니다. 피고만 말할 수 있는 최후 변론 시간이 주어지고 나머지 생존자가 `처형` 또는 `석방`을 선택합니다.

처형표가 석방표보다 많을 때만 집행됩니다. 동률은 석방입니다.

### 8. 사후 수사

사망한 시민 측 참가자와 광대는 생존자의 토론에 다시 개입할 수 없지만, 사건 기록과 공개 단서를 계속 검토할 수 있습니다. 살아 있는 용의자 한 명을 최종 범인으로 봉인하면 게임 종료 시 적중 여부가 개인 화면에 표시되고 15점의 사후 수사 보너스를 받습니다. 이미 동료를 아는 마피아는 이 예측에 참여할 수 없습니다.

## 역할

| 역할 | 소속 | 목표와 능력 |
| --- | --- | --- |
| 마피아 | 마피아 팀 | 밤마다 한 명을 습격하고 동료와 비밀 대화합니다. 마피아 수가 나머지 생존자 수 이상이면 승리합니다. |
| 의사 | 시민 팀 | 밤마다 한 명을 치료해 습격을 막습니다. 자신도 치료할 수 있습니다. |
| 탐정 | 시민 팀 | 밤마다 한 명을 조사해 마피아 여부를 개인 기록으로 받습니다. |
| 경호원 | 시민 팀 | 선택한 사람이 습격당하면 대신 희생됩니다. 9명 이상에서 등장합니다. |
| 시민 | 시민 팀 | 밤 능력은 없지만 단서·질문·투표를 이용해 마피아를 전원 검거합니다. |
| 광대 | 단독 팀 | 시민의 최종 판결로 처형되면 즉시 단독 승리합니다. 6명 이상에서 등장합니다. |
| 관전자 | 관전 | 진행 중인 방에 늦게 들어오면 다음 판까지 사건을 지켜봅니다. |

## 모바일 플레이

검은 자정은 작은 화면에서 데스크톱 UI를 축소하지 않습니다. 모바일 전용 구조를 사용합니다.

| 탭 | 제공 기능 |
| --- | --- |
| 사건 | 현장 감식 단서, 공개된 봉인 증거, 현재 수사 지령, 사건 타임라인 |
| 수사 | 용의자 카드, 공개 의심도, 집중 발언, 질문, 투표와 밤 행동 |
| 대화 | WebRTC 음성 채팅, 공개·비밀 채팅, 빠른 반응 |
| 내 정보 | 비밀 역할, 개인 봉인 증거, 조사 결과, 개인 추리 보드 또는 사후 수사 |

라운드 단계가 바뀌면 필요한 탭으로 자동 이동합니다. 밤 행동, 투표, 토론 이동, 최종 판결 같은 현재 단계의 핵심 행동은 화면 하단 고정 액션 바에 표시됩니다. 이 영역은 모바일 안전 영역과 키보드 높이를 고려합니다.

지원 환경:

- Android Chrome 최신 버전
- iPhone Safari 최신 버전
- 홈 화면 설치가 가능한 PWA
- 데스크톱 Chrome, Edge, Safari, Firefox 최신 버전

음성 채팅을 사용하려면 브라우저의 마이크 권한을 허용해야 합니다.

## 음성 채팅과 진행 음성

`음성 참여`를 누른 참가자끼리 WebRTC 피어 투 피어 방식으로 대화합니다. 게임 서버는 연결 협상 신호만 중계하며 음성 내용을 저장하지 않습니다.

| 단계 | 마이크 상태 |
| --- | --- |
| 대기실 | 참가자 전체 대화 가능 |
| 밤 | 마피아 팀만 비밀 대화 가능 |
| 새벽·결과 발표 | 자동 음소거 |
| 낮 토론 | 생존자 전체 대화 가능 |
| 최후 변론 | 피고만 대화 가능 |
| 최종 판결 | 자동 음소거 |
| 게임 종료 | 참가자 전체 대화 가능 |

진행 음성을 켜면 역할 공개, 밤, 새벽, 토론, 투표, 최후 변론과 결과 전환을 한국어 음성으로 안내합니다. 퀵 모드도 역할 공개 12초, 밤 행동 45초, 자유 토론 최소 90초를 확보해 안내와 조작이 겹치지 않게 구성했습니다.

## AI 플레이어

AI 좌석은 인원이 부족할 때 연습 게임을 완성합니다.

- 역할에 맞는 밤 행동을 수행합니다.
- 마피아 AI는 같은 편을 습격하지 않습니다.
- 토론 중 특정 참가자를 질문하고 공식 진술을 남깁니다.
- 자신이 의심한 대상에게 일관되게 투표하려고 합니다.
- 피고가 되면 최후 변론을 남깁니다.
- 역할별 행동 범위와 공개 수사 흐름을 따라 움직입니다.

현재 AI는 외부 LLM API가 아닌 서버 내부 전략 규칙으로 작동합니다. 별도 API 키나 사용 비용이 필요하지 않습니다.

## 처음 하는 사람을 위한 기능

- 시작 화면과 게임 상단에서 필요할 때 다시 열 수 있는 장면형 규칙 브리핑 제공
- 현재 역할과 단계에 맞는 수사 지령 표시
- 단계 전환 전체 화면 알림과 남은 시간 표시
- 역할별 승리 조건과 생존 전략 제공
- 개인 추리 보드에서 각 용의자를 안전·의심으로 표시
- 종료 후 사건 리플레이와 전체 역할 공개

## 로컬 개발

### 요구 사항

- Node.js 20 이상
- Python 3.11 이상
- Docker와 Docker Compose 권장

### Docker로 전체 실행

```bash
docker compose up --build
```

프런트엔드와 API 주소는 `compose.yaml` 설정을 따릅니다.

### 프런트엔드만 실행

```bash
cd frontend
npm install
npm run dev
```

프로덕션 검증:

```bash
npm run lint
npm run build
```

### 백엔드만 실행

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
uvicorn app.main:app --reload
```

게임 규칙 테스트:

```bash
pytest tests/test_game_flow.py tests/test_ws.py -q
ruff check .
```

전체 데이터베이스 테스트에는 PostgreSQL 연결이 필요합니다.

## 프로젝트 구조

```text
mafia-game/
├─ frontend/
│  ├─ app/                 # Next.js 게임 화면과 반응형 UI
│  ├─ lib/                 # WebSocket, 음성, API, 타입
│  └─ public/              # PWA와 오브젝트 중심 사건 현장 이미지 자산
├─ backend/
│  ├─ app/game.py          # 서버 권위 게임 상태 머신
│  ├─ app/routes/ws.py     # 실시간 방 프로토콜
│  └─ tests/               # 게임·WebSocket·리더보드 테스트
├─ coders.yaml             # coders.kr 배포 정의
├─ compose.yaml            # 로컬 전체 스택
└─ .github/workflows/      # CI
```

| 데이터 | PostgreSQL, SQLAlchemy, Alembic | 로그인 사용자 최고 점수와 리더보드 |
| 배포 | Docker, coders.kr | 웹·API 서비스 운영 |

게임 상태는 서버가 최종 권한을 갖습니다. 클라이언트는 행동 요청만 전송하고 역할, 능력 충돌, 현장 단서, 투표와 승패는 서버가 검증합니다.

## 주요 WebSocket 메시지

클라이언트에서 서버로 보내는 대표 메시지입니다.

| 메시지 | 용도 |
| --- | --- |
| `ready`, `start`, `rematch` | 준비, 시작, 재경기 |
| `fill_bots`, `remove_seat`, `pace` | 방장 제어 |
| `action` | 밤 능력 대상 선택 |
| `chat`, `react` | 채팅과 빠른 반응 |
| `question`, `claim`, `read` | 질문, 공식 진술, 개인 판단 |
| `reveal_lead` | 낮 토론 중 자신의 봉인 증거 공개 |
| `vote`, `judge` | 용의자 투표와 처형·석방 판결 |
| `ghost_predict` | 사망자가 살아 있는 용의자를 최종 범인으로 봉인 |
| `will` | 새벽 마지막 유언 |
| `voice_presence`, `voice_signal` | 음성 참여 상태와 WebRTC 연결 협상 |

서버는 참가자마다 볼 수 있는 정보만 필터링한 `state` 메시지를 보냅니다. 마피아 팀 정보, 조사 결과와 밤 행동은 권한이 없는 참가자에게 전송되지 않습니다.

## 배포

이 저장소는 `coders.yaml`을 포함하고 있어 coders.kr에 바로 배포할 수 있습니다.

1. GitHub 저장소를 연결합니다.
2. 웹과 API Docker 이미지를 빌드합니다.

## 개인정보와 운영 참고

- 음성 데이터는 게임 서버에 저장하지 않습니다.
- 방 상태는 현재 인스턴스 메모리에 유지되며 서버 재시작 시 진행 중인 방이 종료될 수 있습니다.
- 봉인 증거와 공개 의심도는 토론을 만드는 장치이며 실제 역할을 확정하거나 승패를 자동 결정하지 않습니다.
- 사후 범인 예측은 생존자의 판결에는 영향을 주지 않으며, 비마피아 사망자에게만 적중 보너스를 제공합니다.
- 닉네임과 채팅에는 개인 정보를 입력하지 않는 것을 권장합니다.
- 공개 서비스 운영 시 신고, 차단, 채팅 필터, TURN/SFU 음성 서버와 지속형 방 상태 저장을 추가하는 것이 좋습니다.
